# Workspace Rules

## Git Workflow Rule
- **Branching & PR Workflow**: For any code modifications or updates:
  1. Fetch the latest changes from the `main` branch.
  2. Create/checkout a separate development branch named `dev` (or a feature branch if appropriate).
  3. Apply the changes on this branch.
  4. Commit and push the branch to the remote repository.
  5. Create a Pull Request (PR) from the development branch to `main`. Do not push directly to `main`.
